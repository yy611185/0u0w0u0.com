# Fitness V1 真实 iPhone Safari 验收

状态：待真实设备执行。当前自动化已覆盖 Chromium 与 WebKit 的 iPhone 尺寸和触控模拟，但不等同于真实 iPhone Safari。

## 前置条件

- 使用生产地址 `https://0u0w0u0.com/fitness/dashboard`。
- 先在 Cloudflare Access 完成登录；若页面直接打开而没有 Access 登录，先记录为访问保护未启用。
- 记录设备型号、iOS 版本、Safari 版本、日期和网络环境。

## 验收步骤

1. 打开 `/fitness/dashboard`、`/fitness/exercises/goblet-squat` 和 `/fitness/exercises/incline-walk`。
2. 确认两个动作都显示两张静态图；高脚杯深蹲页显示可控循环视频、播放按钮和壶铃参考说明。
3. 从 dashboard 开始一次 Day A 训练：填写重量、次数、RPE，完成一组并刷新页面，确认已保存。
4. 在同一 Safari 标签页继续完成或提前结束训练，打开历史记录，确认实际组数、状态和时长正确。
5. 返回 dashboard，确认进行中的训练可以恢复；重复点击保存和结束按钮，确认没有重复记录或错误推进训练循环。
6. 检查页面没有横向滚动；数字输入不会触发不必要的缩放；主要按钮可稳定点按；键盘出现和收起后布局正常。
7. 播放、暂停、拖动连续视频，确认 Safari 原生控制条可用，视频不会强制全屏或阻塞页面返回。
