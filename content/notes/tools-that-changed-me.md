我喜欢的工具很少用「功能最多」来形容。它们通常有明确的边界，让我更快进入思考，而不是持续管理工具本身。

## 文本、代码与日历

- Markdown 让我把注意力放回内容，并且不被某个平台锁住。
- Git 保存的不只是代码版本，也是一条可以回看的决策路径。
- 日历把抽象的愿望变成真实占用的时间。

工具真正改变我的时刻，是它不再需要被注意的时刻。它安静地待在工作流里，把认知负担留给更值得思考的问题。

比如一个简单的代码块，也应该只是内容的一部分：

```ts
const progress = smallSteps.reduce((work, step) => work + step, 0)
```
